# Solutions library (`docs/solutions/`)

Short, **searchable** write-ups of problems the team already solved — part of **compound engineering** (see `skills/compound-engineering/SKILL.md` and `/compound`).

**Convention:** one topic per file or subfolder, named by problem domain (e.g. `performance/n-plus-one-briefs.md`). Link from tests, PRs, or `AGENTS.md` instead of duplicating prose.
